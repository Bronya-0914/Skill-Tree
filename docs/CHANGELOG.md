## 2026-11-19 — 文件集重寫（現行版本）

### 變更

| 項目 | 內容 |
|---|---|
| 定位 | 改為「上傳一份資料，長出一棵技能樹」；不再以任何既定教材為主軸 |
| 動機 | 明確寫入「看得見的進度」與「每次完成都有成就感」 |
| 使用方式 | 主 README **目錄之前**新增「如何使用」醒目區塊，三種入口：學習者、換課題者、AI |
| AI 可讀 | 新增 [`AGENTS.md`](../AGENTS.md)，單檔雙語＋機讀 YAML 合約 |
| 生成流程 | 訂下兩道阻塞式必問：先問資料、再問答題方式，之後才生成 |
| 誠實規則 | 三種題型依偏好選用；超出範圍才說明落差，不得宣稱已支援 |
| 範圍 | 全部文件一併重寫，定位與用語一致；技術與歷史文件改為通用原則與方法 |

### 理由

先前文件把網站描述成一組固定內容，侷限了「換資料就能換課題」這個核心能力，也沒有把「怎麼用」與「AI 該怎麼接手」放在明顯位置。這版把產品定位、使用入口與 AI 工作流程三者對齊。

### 影響範圍

- 23 份待上傳文件全部更新；新增 `AGENTS.md`。
- 兩份本機交接文件（`START_HERE.md`、`AI_UPLOAD_GUIDE.md`）同步更新份數與目的地對照表。
- **未改動任何程式、教材來源、生成檔或測試**；僅重寫 Markdown。
- 連結、網址覆蓋與測試於交付前重新驗證。
