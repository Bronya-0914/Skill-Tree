# 3000 Solved Problems in Calculus

[English](README.en.md)

依 Elliot Mendelson 原書 46 章的主題安排，重新設計 52 個節點。講解與練習為重新編寫，並非原書 3000 題的完整轉錄。

35 個一般節點各 10 題；17 個較難節點各 4 道長題，每道包含 3–4 個數值小問。一般節點答對 7 題通過；長題節點答對 3 道完整長題通過。小問逐項判分，全部正確才算完成該道長題。

支援整數、小數、分數及數值式，例如 1/2、sqrt(2)、pi。系統使用相對容差 1e-10，答案不含單位，不支援任意含變量的代數等價判定。題目均指定數值結果；近似值請至少保留 10 位小數。

新主題 ID 為 mendelson-calculus，舊 CIS 221 的分數不會轉成新課程完成紀錄。
