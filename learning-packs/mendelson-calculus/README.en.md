# 3000 Solved Problems in Calculus

[繁體中文](README.md)

52 redesigned nodes aligned with the topics of Elliot Mendelson’s 46 chapters. Explanations and exercises are newly written, not a transcription of all 3,000 book problems.

35 standard nodes have 10 numeric questions (pass: 7). 17 advanced nodes have 4 long problems, each with 3–4 numeric parts (pass: 3 complete problems). Each part is checked; all parts must be correct for a problem to count.

Enter numbers, fractions, or numeric expressions such as 1/2, sqrt(2), pi. Relative tolerance: 1e-10. Omit units. General symbolic equivalence with variables is not supported; prompts request numeric results. Keep at least 10 decimal places when approximating.

The new topic ID is mendelson-calculus; CIS 221 scores do not become completion records for this course.
