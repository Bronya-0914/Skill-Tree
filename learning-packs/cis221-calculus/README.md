# 微積分完整學習包

27 個節點，共 270 題。每節點包含教學、公式、逐步例題、10 道四選一練習及逐題解析。答對 7 題即可完成節點。內容以繁體中文撰寫；三角函數使用弧度。

## 在網站學習

1. 網站會自動載入此學習包，無需再次上傳。
2. 點亮 Start，按前置關係逐步學習；支線須完成全部前置節點才會解鎖。
3. 如需在其他相容網站使用，在「主題學習包」上傳 cis221-calculus.zip，預覽後確認匯入。

## 檔案結構

- topic.json：整個主題的名稱、版本和接入位置。
- nodes/*.json：一個檔案對應一個節點，含教學、題庫、解答及前置關係。

如需改題，編輯相應節點 JSON，並提高 topic.json 的 version。在專案根目錄執行 `node scripts/build-learning-packs.cjs`，即可同步更新網站載入檔及 ZIP。也可把 topic.json 和 nodes 資料夾一起壓縮成 ZIP 上傳。保留節點 id 可維持原有學習紀錄。請使用 UTF-8 編碼。
