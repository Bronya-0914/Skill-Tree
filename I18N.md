# Languages

## 繁體中文

右上角與導覽列的語言按鈕可切換繁體中文和英文。選擇儲存在 `skill-tree-language`，並包含在個人備份中。

`js/i18n-messages.js` 是英文對照目錄，以完整、精確的繁體中文字串作為 key，包含內建教材、題目、選項及解析。`js/i18n.js` 負責動態介面訊息、無障礙標籤及語言儲存。

切換時只更新文字與顯示屬性，不重建測驗或畫布、不改進度，也不修改匯入的學習包。原文字保存在 weak map 中以供還原。未知匯入文字保留原語言；要翻譯它們，須新增精確的目錄對照。

修改中文教材時，同步更新中文 key 和英文翻譯，保留公式、ID、答案索引及選項順序。英文節點標題可顯示兩行而不改變樹的幾何佈局。

## English

The top-right and navigation language controls switch between Traditional Chinese and English. The choice is saved under `skill-tree-language` and included in backups.

`js/i18n-messages.js` is the editable English message catalog. Keys are exact Traditional Chinese source strings. It includes every built-in lesson, question, option and explanation. `js/i18n.js` handles parameterized UI messages, accessible labels and language persistence.

Translation updates only text nodes and display attributes. It does not rebuild the quiz, replace canvases, change progress or modify imported learning-pack data. Original text is retained in weak maps for an exact switch back to Chinese. Unknown imported text is displayed in its original language; add exact catalog entries to translate it.

When changing Chinese course wording, update the corresponding catalog key and English value. Keep formulas, IDs, answer indices and option order unchanged. English node titles can wrap onto two lines without changing tree geometry.
